# Gym_API_Project

Fast API based endpoints to acommpany my Gym_DATA_Project to make it easier to input data by having a dedicated endpoints. This eliminates the need to manually enter certain data points in.
Currently I have scale data and cardio data.

THe plan is run this as a docker container on a server via proxmox and secure the endpoint with tailnet so only my phone can send data to it.
